| Standalone cancellation fixture can reclaim foreign swapfiles | Partly fixed | [`fake-unity.sh`](../../../Tools/ship/tests/lib/fake-unity.sh) clears `APK_SWAPFILE` but does not set `APK_SWAP_DIR` or wrap swap commands. This pass addresses the setup license paths, inherited seat marker, and swap reclamation by isolating standalone fixture state. The [harness regression](../../../Tools/ship/tests/linux-unity-harness.test.sh) uses disposable caller paths and a sentinel in place of host swap commands. The APK timeout assertion, inherited runner variables, and the three process cleanup findings remain open.
