# Ship fixture follow-ups

Findings are from the [issue body and comment](https://github.com/abominableenterprise/yetikit/issues/6). The first pass was [PR #136](https://github.com/abominableenterprise/yetikit/pull/136); the remaining five findings were reproduced against [main at `0c3faf4`](https://github.com/abominableenterprise/yetikit/commit/0c3faf4564549f0a5b09d2e6d82cb44808870dfe).

| Finding | Status | Evidence |
| --- | --- | --- |
| Fake Unity and module paths in `Tools/yetikit` | Fixed | The [relocation change](https://github.com/abominableenterprise/yetikit/commit/e2c7de7) made the helper paths local to the bundle. [`linux-unity-modules.test.sh`](../../../Tools/ship/tests/linux-unity-modules.test.sh) resolves the source beside the test; [the vendor gate](../../../Tools/vendor/tests/ship-fixtures.sh) exercises the renamed bundle. |
| Standalone test `sudo` | Fixed | [`ship_fixture`](../../../Tools/ship/tests/lib/fixture.sh) prepends a passthrough stub. [`linux-unity-harness.test.sh`](../../../Tools/ship/tests/linux-unity-harness.test.sh) forces the non-root branch and checks that a sentinel `sudo` is not reached. |
| APK timeout assertion masked by cleanup | Fixed | [The APK check](../../../Tools/ship/tests/linux-unity-apk-swap-recovery.test.sh) preserves the assertion status when removing its stub. [The harness regression](../../../Tools/ship/tests/linux-unity-harness.test.sh) changes the default timeout in a disposable copy: previously the check passed, now it reports the timeout assertion failure. |
| Setup inherits license coordination paths | Fixed in #136 | Standalone [setup](../../../Tools/ship/tests/linux-unity-setup.test.sh) and [launch-window setup](../../../Tools/ship/tests/linux-unity-setup-launch-window.test.sh) use fixture-owned `HOME`/`ULF`. [The harness](../../../Tools/ship/tests/linux-unity-harness.test.sh) checks disposable caller paths stay untouched. |
| Stop fixture leaks its test runner on readiness failure | Fixed | [The stop fixture](../../../Tools/ship/tests/linux-unity-stop.test.sh) tracks its background runner before polling. [The readiness regression](../../../Tools/ship/tests/linux-unity-readiness-cleanup.test.sh) withholds the editor and Xvfb markers in separate runs and checks for escaped processes after the assertion fails. |
| Suite inherits runner-internal state | Fixed | [`tests/run.sh`](../../../Tools/ship/tests/run.sh) unsets `RETURN_ATTEMPTED`, `ACTIVATION_FD`, `EXIT_RC`, and `LINUX_UNITY_RUN`. [The runner regression](../../../Tools/ship/tests/helpers/runner-regressions.py) exports all four to both runners and verifies none reach a fixture. |
| Suite per-file timeout may leak nested process groups | Fixed | [`tests/run.sh`](../../../Tools/ship/tests/run.sh) snapshots nested groups before TERM and retains them through KILL, even after the fixture exits. [The runner regression](../../../Tools/ship/tests/helpers/runner-regressions.py) checks for no surviving synthetic descendants, EXIT cleanup, and continuation to the next file. With a shortened baseline deadline, a nested timeout and its child survived. |
| Standalone seat fixtures inherit `SEAT_STATE` | Fixed in #136 | [`ship_fixture`](../../../Tools/ship/tests/lib/fixture.sh) clears the inherited marker path. [The harness](../../../Tools/ship/tests/linux-unity-harness.test.sh) verifies the marker is written to fixture output, not the caller path. |
| Standalone cancellation fixture can reclaim foreign swapfiles | Fixed in #136 | [`ship_fixture`](../../../Tools/ship/tests/lib/fixture.sh) isolates `APK_SWAP_DIR` and shadows host swap commands. [The harness](../../../Tools/ship/tests/linux-unity-harness.test.sh) checks that a disposable caller's stale swapfile is untouched and sentinel commands are not called. |
| Activation cleanup missing on readiness failure (issue comment) | Fixed | Both activation TERM scenarios [register their runner](../../../Tools/ship/tests/linux-unity-seat-concurrency.test.sh) before waiting for `lc-started`. [The readiness regression](../../../Tools/ship/tests/linux-unity-readiness-cleanup.test.sh) withholds that marker in each scenario and checks that the sandbox and synthetic processes are cleaned up. |
